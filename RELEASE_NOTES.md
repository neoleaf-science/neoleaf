# NeoLeaf: release notes

- **1.35.1**: internal preparation for using your own Git server (Forgejo, Gitea) as the sign-in provider: the code now asks each provider which API dialect it speaks (token renewal, Git login, e-mail address, login rules) instead of comparing with "Codeberg". No change for anyone; sessions, blocks and local copies are read exactly as before.
- **1.35.0**: institution install: an optional `neoleaf.toml` (example in `neoleaf.example.toml`) sets the name, logo, accent colour and contact of an institution, which sign-in providers are on, and where its own Terms and Privacy pages are; with it the home page for people who are not signed in is a plain branded sign-in screen. `neoleaf --check-config` validates the file. Without the file the server works exactly as before.
- **1.34.1**: local agent 0.4.15 (checks of downloaded files and random values updated to the new `sha2`, `rand` and `base64`; no change in what it does). People who already have the agent get the notice or the automatic update as usual.
- **1.34.0**: the code editor is Monaco 0.56 (was 0.45): colours, completion, shortcuts, line wrapping and collaboration work as before. The loader is still checked against a fixed SHA-384.
- **1.33.2**: the project list shows the NeoLeaf version at the bottom of the sidebar, below the contact line.
- **1.33.1**: the PDF viewer uses pdf.js 6.4.299 (was 3.11). The library and its worker are still checked against a fixed SHA-384 before they run, now from a local blob because pdf.js 4 and later are ES modules. Double click on the PDF, zoom and rendering work as before; the workaround for CVE-2024-4367 is no longer needed.
- **1.33.0**: libraries updated: Mermaid 12 (diagrams get the new default look: boxes with shadows and right-angle arrows; long labels in the centre of a mind map are no longer cut), KaTeX 0.19.1 for formulas, Yjs 13.6.33 for collaboration, LightningFS 4.10.3 and isomorphic-git 1.34.2 for Git in the browser. The versions of these files are now pinned and rebuilt by `scripts/build_js_vendor.sh`.
- **1.32.0**: internal libraries updated (sha2 0.11, rand 0.10 and, in the agent, base64 0.23 and windows-sys 0.61); no change in how the editor works. The agent's SHA-256 file check was rewritten for the new sha2 and now has a test with the standard vectors.
- **1.31.8**: Topcoat 0.11 and updated libraries (tokio, serde_json, zip, libc, the agent's ksni, marked 18.1.1 and DOMPurify 3.4.17 for the Markdown preview, Playwright for the tests); no change in how the editor works.
- **1.31.7**: a package that a class asks for with a leading `./` (for example `./abntex2cite.sty`) is now installed automatically; before, the request was ignored and the compilation stopped with "File not found".
- **1.31.6**: the missing BibTeX option file of a package (`abntex2-options.bib`) is now fetched even when the PDF was produced (before, installation only started after a failed compile, and a run with an empty reference list counts as successful); the package index is rebuilt to include it.
- **1.31.5**: projects that use `abntex2` (or another package whose `\bibliography` gets an extra `*-options.bib`) now get that file installed with the package; before, BibTeX could not open `abntex2-options.bib`, skipped the whole `\bibliography` command and the reference list came out empty.
- **1.31.4**: double click on the PDF now leads to where the clicked words are written: a title, an author or a heading that the class prints no longer takes you to the class or to the `\maketitle` line, but to your `\title`, and a paragraph takes you to its own line (SyncTeX often points to the blank line that ends it).
- **1.31.3**: the home page shows the editor in one place: the window at the top now holds the seven screens with their captions (they turn by themselves, with a pause button, and stop when you move through them or ask for less motion), replacing the four old pictures and the separate gallery. The page also no longer grows wider than a phone screen.
- **1.31.2**: the home page has a gallery of seven real screens of the editor (the paper and its PDF, the mind map, reference search, Mermaid, CSV tables, Python and Jupyter notebooks), each with a caption that changes with it; arrows, dots, the keyboard and a swipe move through them.
- **1.31.1**: the home page now describes what the editor does today: Typst, formatting and style checks, spell check, preparing a submission, the GitHub workflow, the formula preview, completing a .bib by DOI, the Typst template and the 15 interface languages.
- **1.31.0**: prepare for submission (checks the project and builds a clean ZIP with only the files the document uses), a GitHub Actions workflow to build the PDF on every push, a formula preview when the mouse rests on a formula, and a smarter ZIP import that detects the main file and the compiler (pdfLaTeX, XeLaTeX, LuaLaTeX or Typst).
- **1.30.1**: LaTeX and BibTeX are drawn in a monospaced font (a style rule had turned the editor text proportional), so the wrap column of the editor is exactly the formatter's width; the project setting is now labelled "Line width (characters)".
- **1.30.0**: line wrapping in the editor can be set per person: at the formatter width (default, in LaTeX and BibTeX), at the window edge, or off. Alt+Z or the editor menu switches it; the choice stays in the browser, not in the project.
- **1.29.1**: compilation errors and warnings were listed twice (once from the log file and once from the console output); each is now listed once.
- **1.29.0**: complete and normalize `.bib` entries by DOI: Crossref (OpenAlex as a backup) fills the missing fields and the window shows every change before it is made; your own values are never replaced unless you tick them.
- **1.28.0**: Format Document for LaTeX and BibTeX (Shift+Alt+F), syntax errors and style findings with quick fixes, and "Fix all style issues", with Badness (MIT) running in the browser as WebAssembly. Settings: style checks on or off, wrap mode and width.
- **1.27.0**: the "New file" window has a file type list (LaTeX, BibTeX, Typst, Markdown, Python and others) that sets the extension; any other name can still be typed.
- **1.26.0**: Typst projects (`.typ`): compiled in the browser with the Typst compiler in WebAssembly, with syntax highlighting, outline, spell check, errors in the editor and a "Typst Article" template. Typst packages are fetched by the browser from packages.typst.org.
- **1.25.0**: spell check: no dictionary is hosted by NeoLeaf any more; the browser asks, downloads the dictionary from GitHub (pinned commit, SHA-256 checked) and keeps it on the device. New dictionaries: Portuguese (Portugal), English (UK), Spanish, French, Italian and German.
- **1.24.3**: spell check: the worker and its library are requested with the build version, so a worker kept in the browser or CDN cache can no longer run with a newer page.
- **1.24.2**: spell check: a dictionary that fails to load is tried again by itself, the notice says why, and the runtime has a longer wait on slow machines.
- **1.24.1**: spell check fixes: the Portuguese dictionary now loads (Hunspell in WebAssembly), the language is detected correctly, languages without a dictionary are not checked, and a failed dictionary shows a notice.
- **1.24.0**: in-browser spell check with Hunspell (Portuguese and English), personal project dictionary and automatic document language detection.
- **1.23.2**: licensing and documentation: self-hosting guide, release workflows for the server and the local agent, neutral wording.
- **1.23.1**: first public release.
