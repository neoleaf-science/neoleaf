{why free compilation?}

Compilation on your own machine: why pay to wait in queues?

Other editors put you in a queue or kill your compilation after 60 seconds with a timeout error to push expensive subscriptions. On NeoLeaf, the processing power is yours:

⚡ WebAssembly (In Your Browser)

100% client-side compilation: runs TeX Live directly inside your browser tab using WebAssembly (texlive-wasm / BusyTeX).

  • ✓
    Absolute privacy: your text is never sent to a remote server for compilation.
  • ✓
    Zero setup: open NeoLeaf and start compiling right away.
  • ✓
    Ideal for conference papers, reports, and Beamer presentations.
  • ✓
    Doesn't burn server quotas and doesn't rely on fast internet.
Native Default · Zero Install
💻 Native Local Agent (Extreme Speed)

Want instant compilation for large theses? The neoleaf-agent links the web UI directly to compilers installed on your computer (TeX Live, TinyTeX, or Tectonic).

  • ✓
    No time limits: compile 400-page documents with zero fear of timeouts.
  • ✓
    Leverages all CPU cores and RAM of your own machine.
  • ✓
    Native support for XeLaTeX, LuaLaTeX, BibTeX, and custom packages.
  • ✓
    Runs in the background with a single install command.
curl -fsSL https://neoleaf.science/install.sh | sh

Linux x86_64, no sudo. The script checks the download's SHA-256. View the script
